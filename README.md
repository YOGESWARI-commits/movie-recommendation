# Movie Recommendation and Rating System

## Overview

A menu-driven Python and SQLite application that allows users to manage movies, genres, ratings, and reviews.

## Features

* Add Genres
* Add Movies
* Add Users
* Rate Movies
* Add Reviews
* View Top Rated Movies
* Filter Movies by Genre
* Recommend Movies

## Technologies Used

* Python
* SQLite

## Database Tables

* genres
* movies
* users
* ratings

## SQL Concepts Used

* AVG()
* GROUP BY
* ORDER BY
* JOIN
* Rating Aggregation

## Recommendation Logic

Movies with average rating greater than or equal to 4 are recommended.
